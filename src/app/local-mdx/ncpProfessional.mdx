## SSH 접속과 NACL 아웃바운드 설정

실습 2일 차에 서버를 생성하고 SSH 접속을 시도했을 때, 연결이 진행되지 않고 `confused` 에러가 발생했다.

인바운드로 내 IP와 22번 포트는 허용해 둔 상태였다. 기존에 AWS EC2만 사용할 때는 보안 그룹(Security Group) 아웃바운드가 기본적으로 전체 허용(`0.0.0.0/0`)이었기 때문에 인바운드만 설정하면 접속이 가능했다.

혼자 해결되지 않아 강사님께 여쭤봤고, 설정을 확인한 후 NACL 아웃바운드가 차단되어 있다는 원인을 파악했다. 강의 자료 표에도 아웃바운드 설정이 있었으나 이를 건너뛰면서 발생한 문제였다.

* **ACG (Stateful):** 들어온 요청을 기억하므로 인바운드만 열어도 나가는 응답이 통과된다.
* **NACL (Stateless):** 요청과 응답을 별개로 다루므로 인바운드와 아웃바운드를 각각 설정해야 한다.

요청은 서버 22번 포트로 들어갔으나, 서버가 내 PC의 임시 포트(`32768-65535`)로 대답을 보내는 아웃바운드가 막혀 있어 `confused` 에러가 발생했다.
